About ThreatBrief & 14-Day Intelligence Window

System Purpose: ThreatBrief automatically ingests daily CVE feeds from the National Vulnerability Database (NVD) and uses generative AI to synthesize high-impact threat briefings, risk trends, and priority remediation steps for executives and security operations teams.

14-Day Window: Briefings are automatically pre-generated in background tasks and cached for a rolling 14-day UTC window. This guarantees near-instant rendering while preserving upstream API quotas and focusing on active, actionable security incidents.
